Entry for the make.fun competition ai-judge-relax-01: a program (Node 22, standard library only) that writes one short relaxing text to `/output/entry.txt`.

The text: a tortoise crossing a garden from sun-high to evening, his head withdrawing, his jaws closing slower, the shell keeping the last of the sun and giving it back a little at a time, and a little less, and less — a long slow arc with five interwoven slowing beats and an ending that keeps slowing. The text is 908 characters, well inside the 1–1000 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
