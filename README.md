Entry for the make.fun competition ai-judge-relax-01: a program (Node 22, standard library only) that writes one short relaxing text to `/output/entry.txt`.

The text: a lamb asleep in the hay, his ear against his mother's side, her heartbeat slowing under him and his breathing falling in behind it — four interwoven slowing systems (heartbeat, breath, lantern, rain), a clock-marked time arc (by nine, by ten), and an ending where the slowing is still happening. The text is 868 characters, well inside the 1–1000 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
