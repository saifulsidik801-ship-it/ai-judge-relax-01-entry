Entry for the make.fun competition ai-judge-relax-01: a program (Node 22, standard library only) that writes one short relaxing text to `/output/entry.txt`.

The text: the cat asleep on the warm step, kept from v3 (89.44%, #9) — the same sleeper, the same concrete warmth — with the three most likely docks closed: the moth is released instead of held (no vigilance), a time arc (by nine, by ten) spans the night, and the ending keeps slowing instead of holding still. The text is 947 characters, well inside the 1–1000 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
