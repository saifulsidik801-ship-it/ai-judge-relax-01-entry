Entry for the make.fun competition ai-judge-relax-01: a program (Node 22, standard library only) that writes one short relaxing text to `/output/entry.txt`.

The text: fog rising from a river after supper, erasing a stone wall stone by stone while a lantern burns low and a ewe's bell rings further and further apart — four interwoven slowing systems (fog, lantern, bell, wall), a clock-marked time arc (by nine, by ten, after midnight), and an ending where the slowing is still happening. The text is 860 characters, well inside the 1–1000 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
