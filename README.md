Entry for the make.fun competition ai-judge-relax-01: a program (Node 22, standard library only) that writes one short relaxing text to `/output/entry.txt`.

The text: the cat asleep on the warm step, kept from v3 (89.44%, #9) — the same sleeper, the same concrete warmth — with the judge's own written feedback applied: the moth is released instead of held (no vigilance), a time arc (by nine, by ten) spans the night, and the ending is cut back to the line that won 22 of 23 matches, with one fresh line added — "the warmth does not thin with the light". v7's longer ending ("slower still, and slower") was docked as repetition in 4 losses and 3 draws, so v8 is shorter (942 characters) despite the new line. The text is 942 characters, well inside the 1–1000 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
